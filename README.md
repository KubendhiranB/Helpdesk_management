# 🛠️ IT Helpdesk Ticketing System 

This is a web application to manage IT support tickets. Users can raise tickets, and the Admin can manage them (view, delete, etc.).

---

## 🚀 Features

- User registration & login
- Ticket creation and tracking
- Admin login and ticket deletion
- SQLite database
- Flask backend

---

## 📂 Folder Structure

```
Helpdesk-Ticket-Application/
│
├── run.py                 # Main file to run the app
├── config.py              # Configuration settings
├── helpdesk.db            # SQLite database file
├── requirements.txt       # Required Python libraries
├── templates/             # HTML files
├── static/                # CSS/JS (if any)
└── create_admin.py        # (Optional) Script to create admin manually
```

## 🧑‍💻 How to Run This Project (Step-by-Step)

### ✅ 1. Install Python

Make sure you have **Python 3** installed.
Download: https://www.python.org/downloads/

---

### ✅ 2. Unzip the Folder

- Right-click the ZIP file → "Extract All..."
- Open the extracted folder.

---

### ✅ 3. Open Command Prompt (or Terminal)

Navigate to the project folder:
```bash
cd path\to\Helpdesk-Ticket-Application
```

---

### ✅ 4. Create a Virtual Environment (optional)

```bash
python -m venv venv
```

Activate it:

- **Windows**:
  ```bash
  venv\Scripts\activate
  ```
- **Mac/Linux**:
  ```bash
  source venv/bin/activate
  ```

---

### ✅ 5. Install Required Libraries

```bash
pip install -r requirements.txt
```

---

### ✅ 6. Run the Application

```bash
python run.py
```

Now open your browser and go to:
```
http://127.0.0.1:5000
```
